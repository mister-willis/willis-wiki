    Fusion Spur Gear Plug-in

    Multi-stage Gears Example

    Installation

    1. Click UTILITIES, then Scripts and Add Ins.

    1. Locate the first SpurGear plug in, slide the switch to the on position, and check the box to run on startup.

    Usage

    1. Start the plugin from the Create menu.

    2. Recommendations for spur gear settings:

    Standard Metric
    Pressure Angle 20 deg
    Module 1 - 2 recommended, based on the overall size you want; both gears must use the same module to mesh with each other, but gears in different stages can use different modules
    Number of Teeth
    Backlash 0.15 mm
    Root Fillet Radius As large as possible
    Gear Thickness 6-8 mm
    Hole Diameter TODO: experiment with 3D printed samples. Need to know: The correct diameter for a tight fit for a gear driven directly by the 6mm D-profile shaft The correct diameter for a tight press fit for the 15mm O.D. ball bearings
