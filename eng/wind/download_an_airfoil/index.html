    Download Airfoil Profile Data

    On the Airfoil Tools site:

    1. Search for your chosen profile(s).
    2. Find the link for the Selig format dat file. Don’t click the link!
    3. Right click the Selig format dat file link and select Save Link As…
    4. Add .dat to the end of the filename and save it to your computer.
