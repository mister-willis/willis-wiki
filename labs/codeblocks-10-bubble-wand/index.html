    Bubble Wand

    Let's write a program to design our own bubble wands!

    Overview

    Instead of drawing a 3D model by hand, you'll write a program that builds one for you. In Tinkercad Codeblocks, each block adds, moves, or changes a shape, and pressing Play runs your program to draw the model. In this lab (Part One of two) you'll build the wand's blower ring, handle, and base — and wire the whole design to variables so one change can resize everything.

    Before you start

    You'll need your Tinkercad account login. Your design saves automatically to your account, and Part Two picks up right where this lab ends.

    You've got it when…

    • Your wand has a blower ring, a handle, and a round base, all built from code blocks.
    • The shapes get their sizes from variables (InnerRadius, Thickness, OuterRadius, Overflow, and Length) instead of plain numbers.
    • Each section of your code starts with a comment saying what it builds.
    • The whole wand is one color.

    Collaboration & AI

    Work: On your own. Ask a neighbor for a hand if you're stuck, but build your own wand.

    AI — AIAS Level 1, No AI: This lab is about learning the blocks by placing them yourself, so set AI aside this time. What the levels mean.

    Add Variables

    Right now every size is a plain number. A variable stores a number under a name, so you can use the name everywhere and change the number in one place.

    1. Scroll to the Math section and click the Create number variable… button.

    2. Name the variable InnerRadius with no spaces and click the OK button.

      Warning

      Variable names can't contain spaces. InnerRadius works; Inner Radius won't.

    3. Drag the Set block to the workspace and set your new InnerRadius variable to 10.

    4. Create and set additional variables the same way so they look like this on your workspace.

      The variables you created are in the Variables section.

    5. Drag the InnerRadius variable to the Radius parameter of the first cylinder, replacing the number 10.

    6. Drag the block from the Math section to the H (height) parameter of the first cylinder.

    7. Drag the variable Thickness to the first space in the block.

    8. Change the number in the second space from 0 to 1.

    9. Change the + to * for multiplication instead of addition.

    10. Change the second cylinder so the Radius is OuterRadius + 1 and the Height is Thickness.

    11. Change the tube so that:

      1. Radius is OuterRadius + Overflow
      2. Wall Thickness is Overflow
      3. H is Thickness + 1

      Why bother with variables?

      The model looks the same as before — so what did we gain? Every size now traces back to a handful of named numbers. In Part Two you'll change one variable and watch the entire wand rebuild itself to match.

    Comments

    Comments help us keep our code organized and easy to read. The computer ignores comments — they are only for us humans to keep things tidy.

    1. Drag a Comment block to the top of the variables in the workspace and label it Variables.

    2. Drag another Comment block to the top of the code we've written so far, and create a comment to remember which part of the bubble wand is created with that code (example: "The circular part of the wand").

    How It's Graded

    This lab is worth up to 4 points. One score covers everything you turn in.

    Score What it looks like
    4 — Excellent Pressing Play draws the whole wand — blower ring, handle, and round base — every shape gets its sizes from your five variables with no stray plain numbers left behind, each section opens with a comment that says what it builds, and the wand is one color.
    3 — Above Average The complete wand draws correctly, with a slip or two — a plain number where a variable belongs, a section missing its comment, or a base that didn't get the color change.
    2 — Average A real gap — the wand is missing a part (a handle floating in space, no base), or the parts are there but sized with plain numbers instead of the variables.
    1 — Below Average Only the blower ring draws, or the program doesn't produce a recognizable wand when Play is pressed.
    0 — Failing No Bubble Wand design in your Tinkercad account, or nothing drawn at all.
