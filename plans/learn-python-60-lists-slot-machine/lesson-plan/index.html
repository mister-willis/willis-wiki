    Lesson Plan — Slot Machine

    Planbook Fields

    Lesson:

    Direct instruction with slides introducing the list: creating one, indexing from zero, and picking from one at random with random.choice. Lab: students build a list of eight slot-machine symbols and a slot function that accepts the list and prints three random picks with a for loop — a working one-armed bandit in under twenty lines. Scored 0–4 on the rubric printed in the assignment.

    Standards: AP CSP AAP-1.C, AAP-1.D, AAP-3.E; AZ CS HS.AP.V.1

    Learning Objectives

    Students will be able to:

    • Create a list of strings and explain zero-based indexing.
    • Select a random element from a list with random.choice.
    • Write a function that operates on a list passed as an argument.
    • Explain why one list beats eight separate variables.

    Standards Alignment

    Code Standard (abbreviated) Why it's defensible here
    AAP-1.C Represent a list or string using a variable. The symbols list is the lab's central object — created, named, and passed around.
    AAP-1.D Develop data abstraction using lists; explain how it manages complexity. Partial (part a, with part b in discussion): the list stores the eight symbols as one value, and the do-now prices the eight-variable alternative so students can articulate what the list saved them.
    AAP-3.E Generate random values; determine possible results. random.choice alongside last lab's randint — two random tools, and the practice slide asks what outcomes are possible (including a triple jackpot).
    HS.AP.V.1 Use lists to simplify solutions instead of repeated simple variables. The standard nearly names this lab: eight symbol variables collapse into one list, and the slot function generalizes to any list you hand it.

    Materials & Setup

    • slides.pptx (this folder) loaded and tested.
    • The symbol characters are in the assignment with a copy button — students copy, then split into strings; no typing emoji by hand.
    • Confirm the student environment renders the symbols; if a console shows boxes, the lab works fine with words ("cherry", "lemon") — say so up front rather than debugging fonts for half a period.
    • Guessing game behind them; import random should be familiar.

    Slides & Direct Instruction

    The deck (7 slides, speaker notes on each) runs: title → what a slot machine really is (a random pick, three times) plus recap of randint → lists and zero-based indexing → choice vs. randint (dark slide — two tools, one module) → the slot function spec → prediction practice → mission slide. Questions worth asking:

    • "Without lists, how would you store eight symbols?" (eight variables — then ask how choice would pick among them; the awkward silence is the lesson)
    • "mylist[0] — which symbol is that?" (the first; zero-based indexing gets planted here and pays off hard in the 2D-list unit)
    • "Can the machine print 💎 💎 💎?" (yes — each pick is independent; that's why jackpots are rare but real, and it's the same idea as rolling doubles)

    Pacing — One 51-Minute Period

    Minutes Segment What happens
    0–4 Settle + do-now On the board: "Store these eight symbols in a program — how many variables, and what are their names?" Let them feel the clunk.
    4–16 Slides Lists, indexing, choice. Build a three-item list live and index into it, including the [0] surprise.
    16–22 Guided try Everyone: make the symbols list, print one random pick. One line of proof before the function.
    22–42 Lab Build the slot function per spec and the main program that passes the list in. Early finishers: add a fourth reel, or a payout message when all three match.
    42–51 Wrap Spin three student machines on the projector; the room judges the payouts. Cold-close: "What does slot know about the symbols?" (nothing — it works on whatever list arrives). Preview: "Next lab, one operator makes the spiral hypnotic — and it's hiding in your times tables."

    ELEOT: The 20-Minute Window

    Item The move in this lesson
    B.2 A complete, satisfying artifact inside one period — small scope, exact spec, visible payoff.
    B.4 The do-now and the "what does slot know?" close both ask students to reason about design, not just syntax.
    C.3 The assignment's list and random references, plus the copy button for symbols, keep students unblocked without a hand in the air.
    D.2 Slot machines, dice, and jackpot odds — probability from the real world the students already argue about.
    D.3 Instruction caps at 12 minutes plus a 6-minute guided try; the rest is building.
    E.1 Rotating notebook check-ins during lab, per the standing system.
    E.3 The projector spins at wrap have students narrating what their function does per iteration.
    E.4 Rubric printed in the assignment; the 4's "works from what it's given, not a global" is checkable by students mid-build.
    F.4 The guided-try checkpoint at minute 22 catches drifting screens before lab time starts burning.
    G.2 Original program in the Python environment, finished and demonstrated the same period.

    Common Student Errors

    • One giant string of all eight symbols instead of eight strings in a list — choice then returns the whole casino at once.
    • Missing commas between list items — adjacent strings silently concatenate, and the list quietly has fewer items than it should; have them print(len(...)) to check.
    • The slot function ignoring its argument and reaching for the global list by name — works today, breaks the moment anyone renames the list; the rubric's 4 names it.
    • random.choice(mylist[0]) instead of random.choice(mylist) — choosing a random character from the first symbol; a subtle one, worth showing.
    • Calling slot without parentheses or without the list — defining a function and never actually running it remains undefeated.

    Assessment & Evidence

    • Deliverable: the slot machine .py (see Turn It In).
    • Score: 0–4 holistic rubric in the assignment. A 4 requires all eight symbols in the list, a loop-driven slot(list), and a main program that passes the list as an argument.
    • Look-fors during check-ins: len of the list is 8; the function's parameter name used inside the body; a student who can predict what slot(["heads", "tails"]) would do without editing anything.
